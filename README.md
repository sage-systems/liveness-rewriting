# Liveness Rewriting with ENABLED
This repository contains the TLA+ specifications used in the thesis "Rewriting TLA+ Liveness Properties for Symbolic Model Checking", and the rewritten ENABLED predicates, alongside properties that use them. The files included can be used to reproduce our results, alongside instructions on how to run them. Original licenses for the specifications used are included in each subdirectory. We release each modification under the same license as its original specification.

The three specifications considered are:
- Traffic Light (Toy Apalache Example)
- EWD840 (Termination Detection Algorithm)
- bcastFolklore (Reliable Broadcast Algorithm)
