# Liveness Rewriting with ENABLED
This repository contains code related to the thesis "Rewriting TLA+ Fairness Conditions for Symbolic Model Checking", as part of the [Research Project](https://github.com/TU-Delft-CSE/Research-Project) at [TU Delft](https://github.com/TU-Delft-CSE).
It contains the TLA+ specifications used in the thesis, the rewritten ENABLED predicates, and the properties that use them. The files included can be used to reproduce our results, alongside instructions on how to run them. Original licenses for the specifications used are included in each subdirectory. We release each modification under the same license as its original specification.

The three specifications considered are:
- Traffic Light (Toy Apalache Example)
- EWD840 (Termination Detection Algorithm)
- bcastFolklore (Reliable Broadcast Algorithm)
